# One Line, One Laugh

Entry for the [make.fun bounty "One Line, One Laugh"](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a).

A program that writes a single funny line to `/output/entry.txt`:

> Warung Bu Yati has sold the same fried rice since 1998, and the price went up exactly once: when her cat had kittens.

## Run

```sh
python3 -P -s main.py
```

Python 3.13, standard library only.
